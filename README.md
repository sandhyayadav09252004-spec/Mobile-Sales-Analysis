
📊 Mobile Sales Dashboard – Power BI

📌 Project Overview

This Power BI dashboard provides an interactive analysis of mobile sales data to help understand sales performance, revenue trends, and customer behavior. The dashboard is designed to support data-driven decision making by presenting key insights in a clear and visual format.


🎯 Objectives

Analyze overall sales performance of mobile products

Track revenue, quantity sold, and profit

Identify top-performing brands and models

Analyze sales trends over time (MTD, YTD, monthly/yearly)

Understand region-wise and store-wise sales distribution



🗂️ Dataset Description

The dataset contains the following key fields:

Sale Date

Mobile Brand

Mobile Model

Quantity Sold

Sales Amount

Profit

Customer / Region / Store 

A custom calendar table is used for time-based analysis.


📈 Dashboard Features

KPIs: Total Sales, Total Quantity, Total Profit

Time Analysis: Daily, Monthly, YTD, MTD

Visuals Used:

Bar Charts (Brand-wise & Model-wise Sales)

Line Charts (Sales Trend over Time)

Cards (Key Metrics)

Slicers (Date, Brand, Region)


Interactive Filtering for better analysis



⚙️ Tools & Technologies

Microsoft Power BI Desktop

DAX for measures (YTD, MTD, Total Sales, etc.)

Power Query for data cleaning and transformation


🔍 Insights Generated

Identification of top-selling mobile brands

Seasonal trends in mobile sales

Comparison of sales performance across time periods

Regions/stores contributing highest revenue


🚀 How to Use

1. Open the .pbix file in Power BI Desktop


2. Refresh the data if required


3. Use slicers to filter by date, brand, or region


4. Interact with visuals to explore insight
   

🧠 Conclusion

This dashboard helps stakeholders quickly understand mobile sales performance and identify growth opportunities. It can be extended further by adding forecasting, customer segmentation, or inventory analysis.
